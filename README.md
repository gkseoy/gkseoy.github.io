# Seoyoung's Blog

Jekyll로 만든 개인 GitHub Pages 블로그입니다.

## 내용 수정

- 이력은 [`resume.md`](resume.md)에서 수정합니다. 각 섹션의 HTML 주석 안에 복사해서 쓸 수 있는 예시가 있습니다.
- 논문 리뷰는 [`_drafts/paper-review-template.md`](_drafts/paper-review-template.md)를 복사해 작성합니다.
- 리뷰를 발행할 때는 파일을 `_posts/YYYY-MM-DD-영문-제목.md` 형식으로 저장합니다.
- `paper-review` 카테고리를 유지하면 홈과 논문 리뷰 페이지에 자동으로 표시됩니다.

## 로컬 실행

```bash
bundle exec jekyll serve
```

브라우저에서 `http://localhost:4000`을 열어 확인할 수 있습니다.
